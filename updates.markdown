This page lists all of Mapbase's released updates. Each row links to the associated article on ModDB, as well as an archival build hosted on Google Drive.

Starting with Mapbase v7.0, major Mapbase versions (e.g. v7.0, v8.0) are distinguished by having changes which break existing saves. Meanwhile, "minor" Mapbase versions (e.g. v7.1, v7.2) do *not* break saves.
